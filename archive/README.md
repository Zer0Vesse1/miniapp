# M_APP 历史版本

此目录按版本保存主要程序的独立快照。归档沿用当前项目的相对路径。日常修改在项目的开发文件中进行。

| 版本 | 归档日期 | 内容 |
| --- | --- | --- |
| [v0.6.0](v0.6.0/) | 2026-11-23 | 烹饪指南 v0.2.0、停车小组件和备份修复，包含 [界面源码](v0.6.0/work/m-app-concept.html)、[独立入口](v0.6.0/index.html)、构建所需文件和 [SHA-256 清单](v0.6.0/SHA256SUMS.txt) |
| [v0.5.0](v0.5.0/) | 2026-11-23 | 全屏模块、进出动效与麻将胡结算 v0.1.0，包含 [界面源码](v0.5.0/work/m-app-concept.html)、[独立入口](v0.5.0/index.html)、构建文件和 [SHA-256 清单](v0.5.0/SHA256SUMS.txt) |
| [v0.4.0](v0.4.0/) | 2026-11-22 | 模块视图、独立设置与版本日志，包含 [界面原型源码](v0.4.0/work/m-app-concept.html)、[测试入口](v0.4.0/index.html)和 [SHA-256 清单](v0.4.0/SHA256SUMS.txt) |
| [v0.3.0](v0.3.0/) | 2026-11-22 | 首个归档基线，包含 [界面原型源码](v0.3.0/work/m-app-concept.html)、[测试入口](v0.3.0/index.html)和 [SHA-256 清单](v0.3.0/SHA256SUMS.txt) |

要验证归档，可用 `Get-FileHash -Algorithm SHA256` 核对清单中的文件。要回看或恢复某版，先把该版本目录复制到独立位置，再按原相对路径使用其中的文件。界面原型可在原来的可视化环境中预览，测试入口可直接在浏览器打开。

`v0.1.0` 和 `v0.2.0` 的历史变更见 [项目更新日志](../CHANGELOG.md)。源码归档从 `v0.3.0` 起算。

本地 Git 使用同名标签定位里程碑。`backup/miniapp-original-index.html` 是更早保留的旧入口，所引用的应用源码不在当前项目中。
