# 颜色转换器前端组件 - Agent开发提示词 (Prompt)

本技术文档定义了一个用于嵌入现有网页的局部小工具（Widget / Component）组件。该组件负责在 RGB（红、绿、蓝）与 Hex（十六进制）颜色代码之间进行双向转换。你可以将此内容直接提供给前端开发 Agent。

---

## 1. 组件开发目标 (Component Objective)

在一个现有网页中添加一个局部的颜色转换器小工具，支持响应式嵌入。组件需完美支持以下两项核心交互功能：
1. **RGB值转十六进制颜色码**：输入红、绿、蓝三个 0-255 的数字，点击转换并预览对应的 Hex 颜色。
2. **十六进制颜色码转RGB值**：输入一个有效的 Hex 颜色代码，点击转换并预览对应的 RGB 数值。

---

## 2. 视觉设计与组件布局规范 (UI/UX Specifications)

### 2.1 容器与整幅排版
* **组件级容器**：整个小工具包裹在一个轻量级的 div 容器中（背景色为纯白 `#FFFFFF` 或透明，由外部父级决定）。组件自带细窄、低对比度的浅灰色边框（如 `1px solid #E0E0E0`）和微小的圆角（`border-radius: 6px`），不带全局阴影，以便自然融入宿主网页。
* **宽度自适应**：宽度采用流式布局（如 `width: 100%` 或可在最大 `600px` 内自适应），确保在宿主网页的侧边栏、主内容区或弹窗内都能完美适配。
* **局部标题**：组件顶部左对齐或居中，使用适中、加粗的深灰色字体（`font-size: 16px; font-weight: bold; color: #333333;`），文本内容为：“**RGB转十六进制颜色转换器**”。
* **区域分割**：内部水平平分为上下两个独立的转换区块，区块之间通过一条细窄的水平分割线（`border-top: 1px solid #EEEEEE`）进行视觉隔离。

### 2.2 上半部分：RGB转Hex区块
* **区块标签**：左上角加粗标明功能：“**RGB颜色值转换成十六进制颜色码：**”，字体较小以适应局部组件。
* **输入组件行**：
  * 包含三个并排的独立数字输入框，依次对应 **R（红）**、**G（绿）**、**B（蓝）**。
  * 输入框外观为白色矩形，带有细灰色边框，文本居中对齐。
  * **初始化默认值**：R 输入框为 `138`，G 输入框为 `92`，B 输入框为 `245`。
* **操作按钮组**：
  * 在输入框右侧紧邻放置两个紧凑型蓝色调按钮，左为“**转换**”，右为“**清空**”。
  * 按钮使用高饱和度的标准蓝色（如 `#006CBF`），文字为纯白，带有轻微的圆角（`border-radius: 4px`）。
* **结果展示与视觉预览**：
  * 在按钮右侧水平排列输出结果。
  * **文本结果**：将转换后的十六进制代码以大写形式（如：**#8A5CF5**）显示，字体颜色必须为**纯正的红色**（如 `#FF0000`），字体加粗。
  * **颜色预览块**：在文本结果右侧紧随一个矩形实心色块（高度与输入框一致，宽度约 `60px`），其填充颜色实时反映当前转换出来的颜色（默认状态下填充 `#8A5CF5` 的紫色）。

### 2.3 下半部分：Hex转RGB区块
* **区块标签**：左上角加粗标明功能：“**十六进制颜色码转换成RGB颜色值：**”。
* **输入组件行**：
  * 包含一个单行的长条文本输入框，用于用户粘贴或输入完整的 Hex 颜色代码。
  * 输入框外观为白色矩形，带有细灰色边框。
  * **初始化默认值**：输入框内默认填充对应的小写 Hex 代码 ` #8a5cf5 `。
* **操作按钮组**：
  * 在输入框右侧紧邻放置两个蓝色调按钮，样式、颜色、尺寸与上半部分完全保持一致，左为“**转换**”，右为“**清空**”。
* **结果展示与视觉预览**：
  * 在按钮右侧水平排列输出结果。
  * **文本结果**：将转换后的 RGB 分量以逗号分隔的形式（如：**138,92,245**）显示，字体颜色必须为**纯正的红色**（如 `#FF0000`），字体加粗。
  * **颜色预览块**：在文本结果右侧紧随一个矩形实心色块（尺寸与上半部分一致），其填充颜色实时反映转换结果（默认状态下填充对应的紫色）。

## 3. 核心交互逻辑与算法行为 (Functional Logic)

### 3.1 RGB转Hex逻辑 (上半部分)
1. **点击“转换”按钮时**：
   * 读取 R、G、B 三个输入框中的文本值，并强制转换为整型（Integer）。
   * **输入合法性校验**：检查每个数值是否在 `0` 至 `255` 之间。若用户留空或数值超出此范围，抛出友好的局部错误提示并终止执行。
   * **核心算法**：将三个十进制整数分别转换为两位的十六进制字符串。如果转换后只有一位，前方必须自动补零以确保固定为两位（例如 `0` 变成 `00`）。
   * 将转换后的三个十六进制片段拼接，并在最前端加上 `#` 号，最终转换为全大写字符串（`138, 92, 245` -> `#8A5CF5`）。
   * **UI渲染更新**：将最终的 Hex 字符串写入红色结果文本中，同时将右侧预览色块的 `background-color` 样式属性同步更新为该颜色。
2. **点击“清空”按钮时**：
   * 将 R、G、B 三个输入框的内容清空。
   * 将红色的文本结果清空，并将预览色块的背景色重置为透明或白色。

### 3.2 Hex转RGB逻辑 (下半部分)
1. **点击“转换”按钮时**：
   * 读取 Hex 文本输入框中的字符串，去除前后可能存在的空格。
   * **输入合法性校验**：利用正则表达式验证输入是否为合法的十六进制颜色格式。标准格式必须允许带或不带 `#` 号的前缀，且有效字符长度应支持 6 位（如 `8a5cf5`）或 3 位（缩写形式，如 `f00` 展开为 `ff0000`）。若校验失败，抛出错误提示并终止执行。
   * **核心算法**：
     * 若为 3 位缩写（如 `abc`），需先展开为 6 位（`aabbcc`）。
     * 去除开头的 `#` 号，将 6 位字符串切分为三个各占两位的子片段（R, G, B）。
     * 将这三个十六进制子片段分别解析为 0-255 之间的十进制整数（例如 `8a` -> `138`，`5c` -> `92`，`f5` -> `245`）。
   * **UI渲染更新**：将这三个十进制数字用英文逗号 `,` 拼接成字符串（形如 `138,92,245`），填入红色的文本结果中。同时，将右侧预览色块的 `background-color` 样式属性同步更新为输入的 Hex 颜色。
2. **点击“清空”按钮时**：
   * 将 Hex 文本输入框的内容清空。
   * 将红色的文本结果清空，并将预览色块的背景色重置为透明或白色。

## 4. 交付与结构要求 (Delivery Requirements)

* **高度模块化**：应当输出高度内聚的 **HTML 模块**、**CSS 样式表** 和 **JavaScript 函数**。
* **样式隔离**：CSS 类名必须使用特定的前缀（例如 `.color-calc-container`, `.color-calc-btn`），防止小工具嵌入现有网页后，其样式与宿主页面的全局 CSS 发生冲突或污染。
* **对齐优化**：由于是高频使用的微型工具，必须利用 Flexbox 确保单行内的输入框、按钮、文本和色块在水平轴和垂直轴上完美居中对齐，杜绝错位。
