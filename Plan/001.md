# 角色与核心任务
你是一个顶级的前端开发专家。你需要重构现有的“高级计算器”网页局部组件，将其升级为一个支持“普通、高级、科学”三种模式一键切换的计算器。

由于本大脑无法直接读取图片，所有 UI 视觉语言已全部转化为定量的前端工程规范，请严格执行以下具体的数值、颜色和布局设定，还原经典的“复古实体拟物、多色拼贴、浅色液晶屏”风格。

## 1. 全局视觉基调（全模式统一适用，严禁使用暗黑风）
为了确保三种模式在切换时视觉风格高度协调统一，所有模式必须共用以下视觉规范：
- **外层容器**：最大宽度限制在 `380px` - `420px` 之间，高密度紧凑紧凑布局。整体背景色使用暗灰色（如 `#2A2B2D`），作为计算器外壳。
- **显示屏区域（液晶屏仿真）**：
  - **背景色**：统一使用极浅的冷青色或灰白色（`#F4F9F9`），模拟真实的低功耗单色液晶屏（LCD）。
  - **文字颜色**：屏幕内所有文字、公式、状态符号统一使用纯黑色或深石墨色（`#111111`），保持极高对比度。
- **物理按键形态与拟物触感**：
  - **按键形态**：微圆角矩形（`border-radius: 4px`），键与键之间保留 `3px - 5px` 的细微网格间隙。
  - **拟物下沉阴影**：每个按键必须自带底边框和微弱阴影：`border-bottom: 2px solid rgba(0,0,0,0.25); box-shadow: inset 0 1px 0 rgba(255,255,255,0.2);`
  - **点击反馈动效**：当按键处于 `:active`（被按下）状态时，触发 `transform: translateY(1px); border-bottom-width: 1px;`，完美模拟实体硅胶按键被按下去的压感。

## 2. 三种模式的布局结构与五大色块分区

在计算器右上角新增一个“设置”图标，点击弹出内嵌菜单 `ModelSelect` 供用户切换模式。切换模式时，重置计算器所有内部状态。

### 2.1 普通计算器模式
- **布局**：$4 \times 5$ 的按键网格。
- **功能键位**：数字 `0-9`, `.`, `+/-`, `%`, `AC`, `+`, `-`, `*`, `/`, `=`。
- **色块规范**：必须强制使用下文【五大色块分区】对应的颜色，严禁使用亮色或薄荷绿皮肤。

### 2.2 高级计算器模式
- **布局与功能**：完全保持你现有的高级计算器既有功能与键位，但必须将按键的背景色、阴影、整体外壳及显示屏颜色，强制同步为本提示词定义的深色外壳+浅色液晶屏拟物风格。

### 2.3 科学计算器模式
- **布局**：高密度紧凑网格布局（建议 $6 \times 9$ 阵列）。
- **结构剔除原则**：**不包含任何顶部菜单栏或下拉菜单功能。直接从第一排物理按键（SHIFT、MENU 行）开始向下排布。**
- **双层显示屏**：
  - **公式输入行（上方）**：字号较小（`14px`），左对齐，实时显示用户输入的完整数学表达式字符串（如 `sin(30) + ln(e^2)`）。
  - **实时结果行（下方）**：字号较大（`28px`，粗体），右对齐，实时显示当前计算结果，未输入完时默认显示 `0`。

## 3. 核心交互行为与算法逻辑（针对科学计算器）

1. **SHIFT 键二阶状态机**：
   - 屏幕左上角保留一个极小的 `S` 状态指示灯。当点击 `SHIFT`（绿色键）后，`S` 指示灯亮起，激活第二层函数映射（如：原本点击 `sin` 键变为触发 `sin⁻¹`；原本点击 `ln` 变为触发 `eˣ`；原本数字 `7` 变为 `n!`）。
   - 第二功能触发一次后，`SHIFT` 状态自动解除，`S` 指示灯熄灭。
2. **双层功能面板丝印文字**：
   - 利用 CSS Grid 配合相对定位，在每个实体按键格子的正下方（或按键上半部分），用极小字号（`10px`）、暗灰色渲染其对应的第二功能文本（例如在数字 `7` 的格子里相伴显示 `n!` 字样），完美还原实体计算器键盘面版效果。
3. **高级表达式解析引擎**：
   - 必须完美支持数学符号的标准优先级，支持 `(` 和 `)` 的多层嵌套。
   - 三角函数支持 `Rad/Deg`（弧度/角度）切换（在屏幕边缘显示当前单位），并严格影响 `sin/cos/tan` 的计算结果。
   - 错误拦截：除法分母为 `0` 或函数输入不合法（如 `log(-5)`）时，拦截计算并在结果行闪烁显示 `Error`。
